## ۳. جفت‌شدگی‌های بحرانی U1

| جفت | ورودی → خروجی | مسئول | ریسک | آزمون |
|---|---|---|---|---|
| هنر ↔ فنی | `pressure` → شعاع نور؛ `complicity` → تیرگی قطره | هنر + فنی | نور کند/سنگین شود | ۶۰fps در حداکثر فشار |
| صدا ↔ AI | حالت FSM ناظم → پن/فاصلهٔ قدم | صدا + AI | ناهم‌گامی صدا با نور | پیمایش: در زدن و روشن‌شدن هم‌زمان |
| UI ↔ بازی | گشتاور بدنی → رویداد domain | UI + بازی | کشف‌نشدن کنش برای بازیکن تازه | پلی‌تست: کشف بی‌آموزش متنی |
| قصه ↔ هنر | متن پایان → ترکیب صحنه (در/کشو/خرده‌کاغذ) | قصه + هنر | پایان شبیه اسلاید شود | بازگویی پایان + یادآوری جزئیات صحنه |
| بازی ↔ صدا | زوال متن → شکست خش | بازی + صدا | تأخیر صدا از زوال | آزمون هم‌گامی |
| فنی ↔ UI | focus/کیبورد → همان کنش کشیدنی | فنی + UI | کنش کیبوردی حس «دکمه» بدهد | آزمون دسترسی با کیبورد |
| AI ↔ بازی | فشار (تلاش/مکث/موتیف) → حالت ناظم | AI + بازی | فشار فقط عددی بماند | پلی‌تست: توصیف حضور ناظم |
