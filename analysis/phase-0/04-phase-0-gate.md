# دروازهٔ فاز صفر

وضعیت کلی: ساختار فاز صفر تأیید شده است. طراحی هر ۲۸ واحد کامل و گزارش DOCX تولید شده و بازبینی/تأیید انسانی را گذرانده است. برش عمودی U1 در Next.js ساخته شده؛ آزمون‌های خودکار و یک پیمایش دودی موفق بوده‌اند. پلی‌تست انسانی U1 انجام شد (P1: رضایت ≈۳۰٪؛ گزارش `05-u1-human-playtest.md`): نتیجه «کد سالم، تجربه ناکافی» — بازطراحی تجربهٔ U1 پیش از آغاز فصل ۱ لازم است. بازطراحی v2 پیاده‌سازی و با آزمون/پیمایش تأیید شده است. پلی‌تست دوم انسانی هنوز اجرا نشده است. بر اساس تصمیم مالک پروژه (۲۰۲۶-۱۰-۲۶)، ساخت واحد دوم فصل ۱ (U2 «کاغذِ درهم») پیش از پلی‌تست دوم آغاز و پیاده شد؛ پلی‌تست دوم U1 به‌موازات اجرا می‌شود و پذیرش U1 دروازهٔ پذیرش U2 است. اعتبارسنجی تجربی مقیاس‌پذیر هنوز انجام نشده است.

## ۵. وضعیت برش U1

- مسیرها: دعوت → پیش‌درآمد → میز → نوشتن/زوال → قفل → تفسیر بدنی → بایگانی → پایان.
- تلاش‌ها: حداکثر ۳؛ تایپ موتیف «سه قطره خون» قفل خودکار ≈۱٫۴ ثانیه‌ای می‌سازد؛ قفل با گذاشتن قلم هم ممکن است.
- تفسیر: سه شیء ادعا + چهار ردِ سنجاق‌شدنی + چهار کنش بایگانی؛ چهار Filing به چهار Ending نگاشت می‌شوند.
- منبع: پیش از پایان در آرشیو پنهان؛ پس از پایان نقل‌قول با شمارهٔ سطر/جمله، بدون بازهٔ کاراکتری و بدون واژگان نظری.
- ذخیره: `three-drops:u1:v1` با `CONTENT_VERSION = three-drops-u1-v2`؛ رخدادمحور با snapshot و بازپخش قطعی.
- صدا: room tone، قدم‌های پن‌دار، در/کشو/پاره‌شدن/مهر/قلم، پژواک موتیف و سکوت گزینشی؛ خاموشی پایدار.
- دسترسی: کاهش حرکت، کنتراست بالا، اندازهٔ متن، ARIA، معادل‌های کیبورد (`K`/`Esc`)، تلهٔ تمرکز مودال و بازگرداندن فوکوس.
- واکنش‌گرایی: ۳۹۰/۸۲۰/۱۲۰۰ بدون سرریز افقی؛ در باریک‌ها پیوند یک‌ستونی و نوار بایگانی داخل جریان صفحه.
- اعتبارسنجی: `npm.cmd run test` (۳۸ موفق)، `npm.cmd run lint`، `npm.cmd run build`، پیمایش مرورگر تا هر چهار پایان، بدون خطای کنسول.
- محدودیت: پلی‌تست دوم انسانی هنوز انجام نشده؛ رضایت ≈۳۰٪ مربوط به v1 است. آزمون واقعی لمس/iOS و روایت صوتی/TTS پوشش داده نشده‌اند.

## ۶. وضعیت برش U2 («کاغذِ درهم» — فیلتر معکوس)

- مسیر: پیش‌درآمد → میز U1 → قفل → تفسیر بدنی → بایگانی (چهار برگه) → «ادامه» (پل هر filing) → کاغذِ درهم → کشف/انکار → دروازهٔ برش («ادامه هنوز ساخته نشده»).
- فعل: برس لمس/ماوس + معادل کامل کیبورد (جهت‌ها + فاصله/Enter)؛ هر ضربه ۱۲٪ از نویزِ پاک‌شده را بیرون از ناحیهٔ ضربه از نو می‌رویاند (نرخ ثابت، بی‌پیام خطا).
- ظهور: سه نقطهٔ نامزدِ محدود با ترتیب seed؛ آستانه‌ها ۵/۱۲/۲۲ ضربه؛ عبارت کاملاً خوانا با شکل‌دهی کامل فارسی؛ درخشش کوتاه + پژواک.
- ثبت/انکار: دفترچه (کلید `K`) فقط پس از ظهور سوم → «خوانا ماند»؛ سفیدی کاغذ (خوانایی ≈۰٫۸) → «کاغذ سفید را رها می‌کنم» → «صفحهٔ خالی».
- ذخیره: `three-drops:session:v1` با `CONTENT_VERSION = three-drops-ch1-v1`؛ رخدادمحور با بازپخش قطعی؛ موقعیت ظهورها در رخداد؛ کلید قدیمی `three-drops:u1:v1` عمداً خوانده نمی‌شود.
- صدا: `brush`/`dust`/`surface` + room tone؛ ناظم در U2 غایب (بدون شاهد منبعی در S011).
- دسترسی: کاغذ فوکوس‌پذیر، `aria-keyshortcuts`، راهنمای srOnly، `touch-action: none`، reduceMotion/highContrast.
- اعتبارسنجی: `npm.cmd run test` (۶۶ موفق در ۹ فایل)، `npm.cmd run lint` (بی‌خطا)، `npm.cmd run build` (موفق)، SSR صفحه بدون خطای رندر (۲۰۲۶-۱۰-۲۶).
- مستندات: `../phase-1/05-u2-experience-design.md`، `../phase-1/06-u2-identity-matrix.csv`، `../phase-1/07-u2-identity-matrix.md`، پروتکل/گزارش `../phase-1/08-u2-playtest-protocol.md` و `../phase-1/09-u2-playtest-report.md`.
- محدودیت: پلی‌تست U2 هنوز اجرا نشده و مشروط به پذیرش U1-P2 است؛ پیمایش بصری دستی مسیرهای فرعی (عرض ۳۹۰، آزمون لمس واقعی) در پلی‌تست انجام می‌شود.
