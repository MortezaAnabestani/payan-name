# شخصیت‌ها

## راوی — میرزا احمد

```yaml
role: بازیکن/راوی/شاهد
want: اثبات روایت و عقل
need: شنیده‌شدن بدون قضاوت
fear: دیوانه‌شمردن، فراموشی، تکرار خشونت
contradiction: می‌خواهد حقیقت بگوید، اما روایت را جعل/تغییر می‌دهد
voice: اول‌شخص، دقیق در جزئیات، دفاعی، گاهی طنز تلخ
body: دست/بازوی بی‌حس، بی‌خوابی، نگاه از پنجره
arc: شاهد → عامل → راوی متهم
game_role: عاملیت محدود؛ حرکت/نوشتن/شلیک/شهادت
```

## سیاوش

```yaml
role: دوست/آینه/رقیب روایت
want: کنترل رابطه و حفظ چهره
need: پذیرش پیامد
fear: افشا/طرد
contradiction: جذاب/مهربان اما صاحب سلاح و خشونت
voice: آرام، توضیح‌دهنده، با خندهٔ دفاعی
body: پیراهن/زیرشلواری، ششلول دسته‌صدفی
arc: میزبان → شاهد → قاضی/برنده
game_role: NPC با حافظه/حالت؛ روایتش با راوی می‌جنگد
```

## رخساره

```yaml
role: نامزد/صدا/انتخاب
want: زندگی/رهایی
need: دیده‌شدن به‌عنوان سوژه، نه جایزه
fear: گرفتارشدن در روایت مردان
contradiction: خنده/گل/آغوش در پایان
voice: کوتاه، کنایی، در پایان قاطع
game_role: NPC/شاهد؛ انتخاب نهایی او بازیکن را قضاوت می‌کند
```

## عباس

```yaml
role: هم‌اتاقی/شاعر/آینهٔ خودفریبی
want: شناخته‌شدن/عشق
need: دیده‌شدن
fear: بی‌ارزشی
contradiction: پیامبر/شاعر/بوسهٔ پنهان
voice: تصنیف، تکرار، خندهٔ احمقانه
game_role: NPC با برنامهٔ روزانه/شعر/رابطه
```

## ناظم

```yaml
role: قدرت/نظارت
want: نظم و کنترل
need: —
fear: از دست دادن اقتدار
contradiction: ظاهر بی‌آزار/خشونت نهادی
game_role: عامل محیطی/تهدید؛ نه هیولای کارتونی
```

## نازی و گربهٔ نر

```yaml
role: عامل غیرانسانی/آینه/قربانی
want: جفت/قلمرو/بقا
need: —
fear: —
contradiction: اهلی/وحشی؛ عاشق/شکارچی
game_role: عاملان صوتی/حرکتی؛ مسیر خون/خون‌آزمایی
```

## شخصیت‌های فرعی

- حسن: بدن/غذا/بقا.
- محمدعلی: نظم/خشونت روزمره.
- صغراسلطان: خودفریبی/بقای زنانه.
- تقی: ایدئولوژی/زن‌ستیزی/تناقض.
- مادر رخساره: قضاوت/خروج.
- دیوانه‌های زندان پایین: خشونت نهادی/تروما.

## قاعدهٔ بازنمایی

- بیماران = انسان/صدا/خواست، نه «دیوانهٔ خنده‌دار».
- زنان = سوژه/انتخاب، نه جایزه/رخنه.
- خشونت بدون نمایش صریح؛ پیامد/صدا/فضا.
- گربه = عامل/شاهد، نه فقط نماد.
