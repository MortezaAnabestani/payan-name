# بریف برش عمودی

## ۱. هدف

ساخت یک برش ۱۵–۳۰ دقیقه‌ای از **باغِ سه قطره** که:

- قصه را قابل‌بازگویی نگه دارد.
- حداقل یک واحد تراگشت را کامل نشان دهد.
- هر هفت حوزه اثر مستقل داشته باشند.
- انتخاب/پیامد/شکست/ذخیره واقعی باشد.
- قابل‌اجرا و قابل‌تست باشد.

## ۲. دامنه

| مؤلفه | داخل | خارج |
|---|---|---|
| مکان | باغ/کاج/دیوار/در آبی | کل آسایشگاه |
| شهادت | ۳ | ۵۹ واحد |
| پایان | ۴ | پایان‌های بیشتر |
| عامل | ناظم/عباس/گربه/رخساره | شبکه/چندنفره |
| صدا | procedural | صداگذاری انسانی |
| هنر | Canvas 2D | سه‌بعدی |
| ذخیره | localStorage | سرور |
| پلتفرم | دسکتاپ + لمسی پایه | موبایل کامل |

## ۳. معیار پذیرش

- [ ] ۱۵–۳۰ دقیقه مسیر کامل — زمان تجربهٔ انسانی هنوز اندازه‌گیری نشده.
- [x] سه ایستگاه + انتخاب + ژورنال — تست خودکار و اسکرین‌شات.
- [x] چهار پایان — `content-test.js` چهار پایان را جداگانه رندر کرد.
- [x] ناظم/تعقیب/گرفتار/checkpoint — تست گرفتارشدن و بازگشت به checkpoint.
- [x] save/load — ذخیرهٔ میانی و ادامهٔ پایان تست شد.
- [x] نور/شنیدن/خون/صدا — پیاده‌سازی و شاهد تصویری؛ ارزیابی شنیداری انسانی نشده.
- [x] RTL/کیبورد/لمسی/بی‌صدا/کاهش حرکت — RTL، کیبورد، لمس افقی و mute تست شد؛ CSS کاهش حرکت موجود است.
- [x] بدون خطای کنسول/بدون asset گمشده — صفر exception و صفر console error در سه تست.
- [ ] آزمون بازگویی — نیازمند بازیکن انسانی.
- [x] برچسب `playtest: unverified` تا تست انسانی — در `playtest/report.md` ثبت شد.

> وضعیت پذیرش: **پیاده‌سازی و تست خودکار pass؛ پلی‌تست انسانی unverified.** معیار زمان و بازگویی تا اجرای انسانی تأیید نمی‌شود.
