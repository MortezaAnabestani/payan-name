# UI/UX

## ۱. اصول

- RTL کامل.
- HUD حداقلی/غیرمزاحم.
- آموزش با فعل، نه دیوار متن.
- هر انتخاب بازخورد فوری.
- دسترسی: زیرنویس/بی‌صدا/کاهش حرکت/کنتراست.

## ۲. صفحه‌ها

### منو

- عنوان؛ شروع/ادامه؛ تنظیمات؛ هشدار محتوا؛ اعتبارنامه.

### بازی

- HUD: هوشیاری (نوار)، نور (دایره)، ژورنال (سه قطره).
- راهنمای فعل در پایین.
- نشانگر تعامل نزدیک.
- هشدار ناظم.

### ژورنال

- سه شهادت.
- متن/تاریخ/منبع.
- بستن با `J`/`Esc`.

### انتخاب

- کارت شهادت.
- دو گزینه.
- پیش‌نمایش پیامد (بدون لو دادن).
- تأیید.

### توقف

- ادامه/ژورنال/تنظیمات/شروع دوباره.

### پایان

- عنوان پایان.
- متن کوتاه.
- آمار: شهادت‌ها/زمان/چرخه.
- شروع دوباره.

## ۳. کنترل

| فعل | کلید |
|---|---|
| حرکت | WASD/جهت‌ها |
| نور | L (نگه‌داشتن) |
| شنیدن | H (نگه‌داشتن) |
| تعامل | E |
| خمیدن | C |
| ژورنال | J |
| توقف | Esc |
| بی‌صدا | M |

## ۴. بازخورد

- انتخاب: لرزش/صدا/تغییر رنگ.
- ناظم: قلب/قرمز/لرزش.
- گرفتار: محو/بازگشت.
- شهادت: مهر/ژورنال.

## ۵. دسترسی

- `prefers-reduced-motion`.
- دکمهٔ بی‌صدا.
- زیرنویس/متن.
- کنتراست بالا.
- اندازهٔ UI.
- بدون وابستگی به رنگ تنها.
