# سه قطره خون — برش عمودی فصل ۱ (U1 + U2 + U3)

تراگشتی تعاملی از «سه قطره خون» صادق هدایت. این نسخه واحدهای ۱ («ناتوانی در نوشتن»)، ۲ («کاغذِ درهم») و ۳ («آسایشگاه به‌مثابۀ جهان»؛ چرخهٔ آسایشگاه) را پیاده می‌کند و عمداً «اعتبارنیافته / پلی‌تست‌نشده» علامت‌گذاری شده است.

## اجرا

```bash
npm install
npm run dev
```

سپس `http://localhost:3000` را باز کنید.

## آزمون و ساخت

```bash
npm test
npm run lint
npm run build
npm start
```

## وضعیت

- مسیر کامل: دعوت → پیش‌درآمد → میز → قفل → تفسیر → پایان U1 → پل → نویز (U2) → دروازهٔ برش → چرخهٔ آسایشگاه (U3) → پایان/مرز فصل.
- چهار پایان U1: پرونده، کاغذ، پاره، سکوت؛ دو پایان U2: خوانا ماند / صفحهٔ خالی.
- U3: چهار ایستگاه (باغچه، زیرزمین، بهداری، شب) + حیاط؛ همهٔ درها به حیاط بازمی‌گردند و چرخه تکرار می‌شود.
- ذخیرهٔ محلی رخدادمحور با بازپخش قطعی.
- صدا، کاهش حرکت، کنتراست بالا و اندازهٔ متن قابل تنظیم است.
- آزمون‌های دامنه و ذخیره در `tests/` قرار دارند.
- متن منبع و طراحی واحدها در `../analysis/phase-0/` است.
