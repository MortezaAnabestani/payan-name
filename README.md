# سه قطره خون — برش عمودی U1

تراگشتی تعاملی از «سه قطره خون» صادق هدایت. این نسخه فقط واحد ۱ («ناتوانی در نوشتن») را پیاده می‌کند و عمداً «اعتبارنیافته / پلی‌تست‌نشده» علامت‌گذاری شده است.

## اجرا

```bash
npm install
npm run dev
```

سپس `http://localhost:3000` را باز کنید.

## آزمون و ساخت

```bash
npm test
npm run lint
npm run build
npm start
```

## وضعیت

- مسیر کامل: دعوت → پیش‌درآمد → میز → قفل → تفسیر → پایان.
- چهار پایان: پرونده، کاغذ، پاره، سکوت.
- ذخیرهٔ محلی رخدادمحور با بازپخش قطعی.
- صدا، کاهش حرکت، کنتراست بالا و اندازهٔ متن قابل تنظیم است.
- آزمون‌های دامنه و ذخیره در `tests/` قرار دارند.
- متن منبع و طراحی واحدها در `../analysis/phase-0/` است.
