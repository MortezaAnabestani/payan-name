# ۱۲ — برش عمودی

## ۰. تعریف

برش عمودی، **یک تجربهٔ کامل و قابل‌بازی** از یک واحد اثر است که همهٔ هفت حوزه را در مقیاس کوچک نشان می‌دهد.

برش عمودی نیست:

- ماکاپ UI.
- صفحهٔ HTML با متن.
- مجموعهٔ asset.
- «دموی فنی» بدون قصه.
- «نمونهٔ همه‌چیز» بدون عمق.

## ۱. هدف

- اثبات اینکه کانسپت کار می‌کند.
- اثبات اینکه قصه/جهان قابل‌تجربه است.
- اثبات اینکه مسلط‌زدایی قابل‌ادراک است.
- اثبات اینکه هفت حوزه هم‌کاری می‌کنند.
- تولید شاهد برای پذیرش/سرمایه‌گذاری.

## ۲. دامنه

| مؤلفه | حداقل |
|---|---|
| مدت | ۱۵–۳۰ دقیقه |
| واحد روایی | یک واحد کامل با آغاز/میانه/پایان |
| واحد تراگشت | ۱–۲ |
| مکان | ۱–۳ فضای به‌هم‌پیوسته |
| فعل | ۱ اصلی + ۱–۲ فرعی |
| NPC | ۱ عامل با رفتار حالت‌مند |
| انتخاب | ۱ انتخاب با پیامد |
| نبرد/چالش | ۱ چالش یا مانع |
| هنر | محیط/شخصیت/انیمیشن/VFX حداقلی |
| صدا | موسیقی/امبیانس/SFX/فضایی |
| UI | HUD/منو/آموزش/بازخورد |
| فنی | بیلد/ذخیره/بارگذاری/کارایی |
| پلی‌تست | ۵ بازیکن |

## ۳. ساختار تجربه

```text
آغاز/ورود
  → آموزش فعل
  → اولین مانع
  → کشف/رابطه
  → نقض پروتکل
  → انتخاب
  → پیامد
  → تعلیق/بازآرایی
  → پایان/دعوت به ادامه
```

### ۳.۱ آغاز

- بازیکن کجاست؟
- چه می‌بیند/می‌شنود؟
- اولین فعل چیست؟
- چه سؤالی در ذهنش می‌ماند؟

### ۳.۲ آموزش

- با فعل، نه متن.
- یک هدف کوچک.
- بازخورد فوری.
- اجازهٔ اشتباه.

### ۳.۳ نقض

- پروتکل چه زمانی می‌شکند؟
- چگونه بازیکن می‌فهمد عمدی است؟
- چه چیزی قبلاً یاد گرفته که حالا ناکافی است؟

### ۳.۴ انتخاب/پیامد

- انتخاب چه چیزی را تغییر می‌دهد؟
- پیامد فوری/تأخیری.
- آیا قابل بازگشت است؟

### ۳.۵ پایان

- پایان صحنه.
- حالت/ذخیره.
- دعوت به ادامه.
- پرسش باقی‌مانده.

## ۴. هفت حوزه در برش

| حوزه | شاهد در برش |
|---|---|
| بازی | فعل/حلقه/هدف/شکست/انتخاب |
| فنی | بیلد/ذخیره/دوربین/کارایی |
| AI | NPC با رفتار قابل‌مشاهده |
| هنر | فضا/شخصیت/انیمیشن/نور |
| UI | آموزش/HUD/بازخورد |
| صدا | موسیقی/امبیانس/SFX/فضایی |
| داستان | قصه/دیالوگ/مأموریت/پیامد |

## ۵. خروجی

```
slice/

  build/
  assets/
  audio/
  ui/
  ai/
  save/
  playtest/
  acceptance.md
```

## ۶. معیارهای پذیرش

- [ ] ۱۵–۳۰ دقیقه بازی.
- [ ] یک واحد کامل.
- [ ] همهٔ هفت حوزه قابل‌مشاهده.
- [ ] NPC رفتار دارد.
- [ ] انتخاب پیامد دارد.
- [ ] شکست/بازگشت کار می‌کند.
- [ ] ذخیره/بارگذاری کار می‌کند.
- [ ] بیلد روی پلتفرم هدف اجرا می‌شود.
- [ ] ۵ بازیکن بیرونی tested.
- [ ] قصه قابل بازگویی است.
- [ ] مسلط‌زدایی قابل‌ادراک است.
- [ ] باگ‌های بحرانی صفر.

## ۷. برش عمودی به‌عنوان شاهد

برش عمودی باید:

- یک تریلر ۶۰–۹۰ ثانیه‌ای داشته باشد.
- یک ویدیوی پلی‌تست ۵ دقیقه‌ای.
- یک گزارش پذیرش.
- یک فهرست «چه چیزی هنوز نیست».

**قاعده:** برش را «بازی کامل» معرفی نکن. شفاف بگو چه چیزی برش است.

## ۸. توقف

اگر برش:

- بازی نیست،
- قصه ندارد،
- هفت حوزه را نشان نمی‌دهد،
- یا مسلط‌زدایی‌اش قابل‌ادراک نیست،

به تولید کامل نرو. اول برش را درست کن.
